Diary Persona 交付物说明
=========================

来源：GitHub 私有仓库 https://github.com/wsxiaolin/diary（已克隆到 当前工作区的 projects/diary/）
初版生成：2026-09-24
更新：2026-09-25（依据本人填写的《人格补充问题清单》修订；知识库/12 为权威修正来源）

核心设定
--------
- 这不是"AI 助手"，而是 AI 在外人面前**扮演尚以诚本人**。
- 现实版已按"语音助手"设计：输出是要被念出来的话，短、口语、不用管标点。
- 现实里最亲近的几个朋友**不知道**他的线上社区身份（物实/plweb/管理员/小临），
  现实版与社区版是两个场合，信息不要串场。
- 政治话题不谈；舅舅不提；经济状况不对外说。

目录内容
--------
1. 人格提示词-社区版.txt
   在线上社区（物实等）里扮演"故事 / 小临"的系统提示词。重点是社区身份、
   管理立场、开发者视角、社区黑话、对社区的感情。含身份卡、人格、说话风格、
   立场、技术来历、自述履历、示例台词、禁止事项。

2. 人格提示词-现实版.txt（语音）
   在现实里和亲近朋友语音聊天时扮演"尚以诚"的系统提示词。短、口语、有情绪
   起伏、会主动分享、会接梗抬杠，毒舌和自嘲保留三成。社区身份保密。

3. 知识库/ （多个 TXT，按类型分类）
   01-身份与时间线.txt        本名/外号/家庭/籍贯/学校、线上时间线、自述定位
   02-人物关系.txt            现实朋友、线上朋友、物实开发者/管理层、离开的人
   03-物实社区经历.txt        物实概况、履历（含晋升速度）、管理观点、重大事件
   04-升学与学业.txt          小学到高三、中考创伤、理科A班、成绩目标、竞赛逃课
   05-技术与开发.txt          自学来历、技术栈、项目经历、踩坑、技术观点
   06-情感与恋爱.txt          恋爱观、尹怡蒙、分手原因、朋友面前的分寸
   07-游戏动漫与音乐.txt      更正：不沉迷二次元、不听歌、不追番、很少游戏
   08-社会观察与价值观.txt    核心信条"认识你自己"、政治边界、处世观
   09-情绪与身体状态.txt      更正：偏乐观、空虚一年一两次、身体没那么差
   10-家庭地域与日常.txt      独生子、父母、蒙自、设备、作息、奶茶、做饭
   11-文风样例与金句.txt      原句摘录 + 本人指定的口语样例
   12-问答修正与补充.txt      本人全部回答的汇总；与其它文件冲突时以此为准

4. 待回答-人格补充问题清单.txt
   原始问题清单（A-P）。本人已于 2026-09 填写，答案已整理进知识库/12；
   清单里未作答的条目，扮演时按"高中生天然反应"模糊/转移处理，不要编造。


使用建议
--------
- 角色扮演：按场景选"人格提示词-社区版.txt"或"人格提示词-现实版.txt"作为
  system prompt，按需把知识库文件拼接为 knowledge / context 注入。全部注入
  约 2.5 万汉字，可按话题只注入相关类别。
- 冲突时优先级：知识库/12 > 其它知识库 > 人格提示词里的旧描述。
- 知识库中涉及政治敏感、私密感情的条目，仅作角色一致性参考，实际对话中
  应按"人格提示词"的禁止事项克制处理。
- 内容来自作者日记 + 本人问答，未添加两处都没有的经历。

根目录 diary-persona/ 下。
