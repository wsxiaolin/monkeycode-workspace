Diary Persona 交付物说明
=========================

来源：GitHub 私有仓库 https://github.com/wsxiaolin/diary（已克隆到 当前工作区的 projects/diary/，共 35 个文件）
生成日期：2026-09-24

目录内容
--------
1. 人格提示词-社区版.txt
   在线上社区（物实等）里扮演"故事 / 小临"的系统提示词。重点是社区身份、
   管理立场、开发者视角、社区黑话、对社区的感情。含身份卡、人格、说话风格、
   立场、技术风格、示例台词、禁止事项。

2. 人格提示词-现实版.txt
   在现实中与朋友/同学/家人交流时扮演"故事 / 小临"的系统提示词。社区与开发
   身份只作背景，篇幅更短，侧重性格、口语风格、现实生活话题、价值取向。

3. 知识库/ （多个 TXT，按类型分类）
   01-身份与时间线.txt        基本身份、人生大事时间线、自述定位
   02-人物关系.txt            物实开发者/管理层、朋友、离开的人、二次元人物
   03-物实社区经历.txt        物实概况、履历、管理观点、重大事件、对社区的感情
   04-升学与学业.txt          中考经历、高中节奏、对教育的批判、英语瓶颈
   05-技术与开发.txt          技术栈、项目经历、踩坑经验、技术观点
   06-情感与恋爱.txt          情感观、感情时间线、名句
   07-游戏动漫与音乐.txt      Galgame、手游动漫、音乐审美
   08-社会观察与价值观.txt    核心价值、对教育与互联网的批判、处世观
   09-情绪与身体状态.txt      虚无/怀旧/烦躁/孤独、身体状态、内心独白
   10-家庭地域与日常.txt      家庭、地域旅行、日常琐事
   11-文风样例与金句.txt      按场景摘录的原句，用于校准语感

4. 待回答-人格补充问题清单.txt
   日记缺失的经历与细节问题清单（A-P 共 160+ 条），供本人一次性作答后补全
   人格与知识库。带★为最影响"像不像"的问题，带※为隐私可选。


使用建议
--------
- 角色扮演：按场景选"人格提示词-社区版.txt"或"人格提示词-现实版.txt"作为
  system prompt，按需把知识库文件拼接为 knowledge / context 注入。全部注入
  约 2 万汉字，可按话题只注入相关类别。
- 知识库中涉及政治敏感、私密感情的条目，仅作角色一致性参考，实际对话中
  应按"人格提示词"的禁止事项克制处理。
- 所有内容均来自作者公开日记，已做归类与整理，未添加日记中不存在的经历。

根目录 diary-persona/ 下。
